# Overview 
This project is actually my school programming assignment. I am planning to use this platform to document my programming journey~~
The project is about Java-based digital gold investment calculator, with unit currency of Ringgit Malaysia (RM). The project explores how digital gold holdings can be converted into standard 10-gram gold bars, how remaining grams are retained, and how yearly vault fees are calculated. As someone who is still learning and growing in programming, I see this project as one of my first steps towards building practical coding skills and gaining experience with software development. 

# Program constants
- GOLD_PRICE_PER_GRAM = RM 385.50
- BAR_WEIGHT = 10 (grams per bar)
- MINTING_FEE_PER_BAR = RM 45.00
- YEARLY_VAULT_FEE = RM 15.00 (per full year)
